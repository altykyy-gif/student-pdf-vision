# Student PDF Vision

واجهة GitHub Pages عربية لتحليل قوائم الطلبة PDF عبر خادم Gemini متعدد الوسائط.

GitHub Pages يستضيف الواجهة فقط؛ شغّل `backend/app.py` على Render أو Railway أو Cloud Run، ثم ضع عنوانه في `github-pages-config.js`. لا تضع مفتاح النموذج في المستودع.

راجع [دليل النشر](GITHUB_PAGES_DEPLOY.md).
